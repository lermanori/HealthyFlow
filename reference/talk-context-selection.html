Three statuses that cannot be swapped

StatusMeaningAllowed answer
connected_emptyThe connected Calendar was read and returned no events.“No Calendar events found for this date.”
not_readThe device did not supply this date.“I have not checked that date.”
unavailableThe Calendar read failed.“I could not read your Calendar.”

Review rule

Before accepting an answer, check: (1) Was the date and subject resolved from the conversation? (2) Were all required sources read? (3) Does each claim match a successful source read?

The router can propose a read plan. Application code validates dates and source dependencies. If evidence is missing, the app requests it or Talk states the limitation. It never turns a failed or omitted read into an empty day.
