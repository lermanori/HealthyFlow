# Siri Capture Resources

## Knowledge

- [Apple: App Intents](https://developer.apple.com/documentation/appintents)
  Framework overview for exposing app actions to Siri, Shortcuts, Spotlight,
  widgets, and other system surfaces.
- [Apple: Creating your first app intent](https://developer.apple.com/documentation/appintents/creating-your-first-app-intent)
  Use for the `AppIntent`, parameter, execution-mode, and result lifecycle.
- [Apple: Adding parameters to an app intent](https://developer.apple.com/documentation/appintents/adding-parameters-to-an-app-intent)
  Use for the required `String` capture parameter and parameter summary.
- [Apple: App Shortcuts](https://developer.apple.com/documentation/appintents/app-shortcuts)
  Use for Siri phrases, discovery, shortcut metadata, and registration.
- [Apple: Intent authentication policies](https://developer.apple.com/documentation/appintents/intentauthenticationpolicy)
  Use when deciding whether capture is available while the device is locked.
- [Apple: App Intent supported modes](https://developer.apple.com/documentation/appintents/appintent/supportedmodes)
  Use when evolving the shortcut between background capture and foreground
  review; this is the modern replacement for `openAppWhenRun`.

## Wisdom (Communities)

- [Apple Developer Forums: Intents](https://developer.apple.com/forums/tags/intents)
  Use for device- and OS-specific Siri discovery/debugging problems after the
  implementation follows the official framework contract.
