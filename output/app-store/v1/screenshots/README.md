# HealthyFlow App Store screenshot drafts

Five 1320 × 2868 marketing screenshots using Toki's bold composition with a distinct HealthyFlow identity: forest-to-sage-to-warm-cream gradients, short white headlines, and large iPhone mockups containing unmodified HealthyFlow captures.

## Set

1. Today — `Your whole day. One place.`
2. Talk — `Talk it through. Plan your day.`
3. Health — `Everything health. One daily view.`
4. Nutrition — `Food fits into your day.`
5. Workouts — `Make time to feel stronger.`

The app captures use fictional data in the isolated `HealthyFlow Screenshots` simulator. Talk contains a genuine generated response. The Talk composition crops the simulator-only transcription warning outside the visible phone area; the underlying capture is unchanged.

## Status

Uploaded to App Store Connect on 2026-09-18 in the iPhone 6.5-inch slot, in this order: Today, Talk, Health, Nutrition, Workouts. Apple accepted all five 1242 × 2688 files and will reuse them for the other iPhone display sizes and localizations unless custom media is added.

Uploaded to App Store Connect on 2026-09-18 in the iPad 13-inch slot, in this order: Today, Goals, Health, Nutrition, Workouts. Apple accepted all five 2064 × 2752 files and will reuse them for the other iPad display sizes and localizations unless custom media is added.

Before final review submission, compare the images with the final signed release candidate so the represented interface still matches the submitted build.

## Render

Open `designs.html?shot=1` through `designs.html?shot=5` at a 1320 × 2868 viewport and take full-page PNG screenshots. Open `designs.html?shot=all` at 1800 × 830 for the contact sheet.

For the App Store Connect 6.5-inch slot, open `designs.html?shot=1&size=65` through `designs.html?shot=5&size=65` at 1242 × 2688. The files in `exports-6.5/` are the upload-ready versions.

The 13-inch iPad set is authored in `designs-ipad.html` and exported at Apple's native 2064 × 2752 size in `exports-ipad-13/`. It uses Today, Goals, Health, Nutrition, and Workouts; the isolated iPad session could not load saved Talk conversations, so the set does not advertise a screen containing an error state.
